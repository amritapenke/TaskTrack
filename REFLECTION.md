## 1. Development Process

I continued developing my TaskTrack Python application using Git and GitHub to track my progress. I added persistent task storage, improved the task viewing feature, and updated the project documentation.

## 4. Importance of Version Control

Git helped me organize changes into separate commits, while GitHub allowed me to store my project remotely. The commit history provides a record of how the application developed.
